# E-Learning Platform Database System

## Overview
This project is a relational database system designed for an e-learning platform. The database manages students, instructors, courses, enrollments, assignments, submissions, grades, and attendance records.

## Tools Used
- MySQL 8.0
- MySQL Workbench
- draw.io
- GitHub

## Features
- Student and instructor management
- Course enrollment tracking
- Assignment and submission management
- Grade tracking
- Attendance tracking
- Relational database design using primary and foreign keys
